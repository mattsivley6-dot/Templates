# Texas Public-Entity Bid - Disqualification Prevention Checklist

A reusable checklist for Texas public bids (RFCSP / CSP / ITB on Jaggaer, Ionwave, and district portals). Copy this into each new job folder and work it top to bottom. The items in **CAPS / bold** are the ones that get good bidders thrown out on a technicality.

Statute and form references are for orientation only. Check the current official text and the solicitation itself before relying on any of them.

---

## 0. Read-first (the DQ landmines)

These four mistakes cause more rejections than price ever does:

1. **HSP / HUB SUBPLAN IS A SEPARATE SUBMISSION.** On most state and ISD work the HUB Subcontracting Plan is submitted as its own sealed item, on its own deadline, sometimes to a different inbox or upload slot than the proposal. A missing or late HSP is an automatic non-responsive finding even if your price wins. Treat it as a second, parallel deliverable from day one.
2. **EVERY ADDENDUM MUST BE ACKNOWLEDGED.** Check the portal for addenda up to the closing hour. Failing to acknowledge an addendum (especially one that changed scope or the form set) is a classic DQ.
3. **PORTAL CLOCK, NOT YOUR CLOCK.** Jaggaer / Ionwave close on the server's time to the second and lock you out. Upload a complete set hours early; never let final price be your last upload.
4. **SIGN AND NOTARIZE WHAT THEY SAY TO.** Unsigned bid form, missing notary/seal on the bid bond, or a blank conflict-of-interest box voids the whole package.

## 1. Solicitation intake (do this the day the bid lands)

- [ ] Confirm vehicle and statute: RFCSP (Tex. Educ. Code 51.783, higher-education institutions), CSP (Tex. Gov't Code Ch. 2269), or competitive bid. Note which, it changes the rules.
- [ ] Record owner, using agency, engineer of record, and the procurement contact.
- [ ] Record key dates in the job notes and your tracker: pre-bid/bidwalk (mandatory?), RFI deadline, **addendum cut-off**, **proposal due date and exact time**, and **separate HSP due date/time if different**.
- [ ] Confirm submission platform and method (Jaggaer, Ionwave, district e-bid, or sealed paper) and that you have a working login before the last day.
- [ ] Download the full set: project manual, drawings, all forms, sample contract, insurance and bonding requirements.
- [ ] Note whether a mandatory pre-bid or site visit is required. Missing a mandatory walk = ineligible.

## 2. Compliance requirements to confirm (per solicitation)

- [ ] **HUB / HSP goal**: percentage goal, the exact HSP form/version, good-faith-effort documentation, and whether it is a separate sealed submission. Start the HSP outreach early (the form often requires documented solicitations to 3+ HUBs).
- [ ] **Domestic iron and steel / Buy America**: Tex. Gov't Code 2252.202 (iron and steel products produced in the United States) and any federal Buy America terms if federally funded; get supplier certifications in writing.
- [ ] **Prevailing wage**: Tex. Gov't Code Ch. 2258, the applicable wage rate schedule attached, and the certified payroll obligation (and any apprenticeship/utilization terms).
- [ ] **Bonding**: bid bond (amount/%), and whether payment and performance bonds are required at award; confirm surety can issue at the required A.M. Best rating.
- [ ] **Insurance**: required limits and endorsements (additional insured, waiver of subrogation, primary/non-contributory); confirm your COI can be issued to match.
- [ ] **Felony / criminal-history and SB 9 fingerprinting** (ISD work): contractor certification re: covered employees.
- [ ] **Form 1295** (Certificate of Interested Parties) filing with the Texas Ethics Commission at award, and acknowledged in the proposal if asked.
- [ ] **Conflict of Interest Questionnaire (CIQ)** if applicable.

## 3. The form set (the package that gets graded)

Build a per-job folder mirroring your usual layout and check each required item off. Typical Texas ISD / public package:

- [ ] Proposal / bid form (every line, every alternate, base bid and unit prices) - signed
- [ ] Execution-of-offer / signature page - signed, with the exact legal entity name: [Legal Entity Name]. Add the DBA ([Company DBA]) only where the form asks for one.
- [ ] Addenda acknowledgment - all numbered addenda checked
- [ ] Bid bond - correct amount, surety seal, power of attorney attached, dated
- [ ] HUB Subcontracting Plan (HSP) - complete, with good-faith-effort docs - **submit per its own instructions**
- [ ] Conflict of Interest Questionnaire (CIQ) - complete (even if "none")
- [ ] Form 1295 - prepared (file with TEC and bring the certification)
- [ ] W-9 - current
- [ ] Insurance requirements form / sample COI - acknowledged
- [ ] References / similar-project experience (a contractor qualification statement, if requested)
- [ ] Key personnel / superintendent and PM resumes if requested
- [ ] Schedule / time of completion and any liquidated-damages acknowledgment
- [ ] Buy America / prevailing wage / drug-free workplace / debarment certifications as required
- [ ] Any agency-specific forms (standard terms acceptance, evaluation form, vendor setup)

## 4. Scope and number integrity (don't lose money or get RFI'd out)

- [ ] Drawings are the source of truth; validate the project-manual scope against the drawings and cross-check your scope breakdown.
- [ ] Confirm Division 23 scope and flag big non-HVAC divisions you are responsible for (electrical, controls, TAB, commissioning, roofing/curbs, demo).
- [ ] All referenced sheets present; submit an RFI before the RFI deadline for any missing sheet or conflict.
- [ ] Alternates, allowances, and unit prices captured and priced.
- [ ] Sub and vendor quotes match the current addenda scope, not an earlier version.
- [ ] Sales tax treatment correct for the entity (most TX public work is tax-exempt to the owner).

## 5. 48 hours before close

- [ ] Re-check the portal for a last-minute addendum; acknowledge it.
- [ ] Assemble the complete package and do a second person review against Section 3.
- [ ] Confirm the HSP path again (separate upload/inbox/deadline).
- [ ] Dry-run the upload: file naming, file count, file size limits, required file types.
- [ ] Bid bond original handling confirmed (some still want a physical original).

## 6. Submission (do not do this in the last 30 minutes)

- [ ] Upload / deliver a complete set with margin (target: done 2+ hours early).
- [ ] Upload the HSP to its correct slot.
- [ ] Capture the portal confirmation / receipt and save it to the job folder.
- [ ] Verify every file actually uploaded (open them back from the portal if possible).

## 7. After close

- [ ] File Form 1295 with the TEC if you are in line for award.
- [ ] Save the tabulation / results to the job folder and to your lessons learned file.
- [ ] Note any DQ'd competitor and why (free intelligence for next time).

---

### Quick "will I get DQ'd?" gut check
HSP submitted correctly and on its own deadline? All addenda acknowledged? Every required form signed? Bid bond sealed and dated? Uploaded early with a saved receipt? If all five are yes, a technicality cannot knock you out.
