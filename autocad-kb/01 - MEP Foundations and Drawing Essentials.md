## 1. What the toolset is

- Toolset for the MEP disciplines (mechanical, electrical, piping, plumbing) in building design. It holds: catalogs of drawing objects that model real parts and connect intelligently; discipline tools such as system sizing; common tools (project management, design preferences for how objects look and behave); drawing templates with standards-based settings. ([G:B5A862C6](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B5A862C6-9CE5-4C27-9D3B-49AE9C7C3D88))
- It is object-based. Objects include segments of duct, pipe, cable tray and plumbing line, fittings of all types, and equipment called multi-view parts (MvParts) such as air handling units, transformers and drinking fountains. ([G:81D983B1](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-81D983B1-A719-4007-8A22-E26BE5A9C891))
- Objects are built from lines, arcs and other AutoCAD geometry but carry extra data. Their connectors join to suitable objects and pass shape, size and system. ([G:81D983B1](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-81D983B1-A719-4007-8A22-E26BE5A9C891))
- Example: draw duct from a VAV box connector and the software reads the connector size and shape and draws a matching duct. It inserts sized fittings as you lay out segments, a transition where segment size changes, and keeps connectivity when you modify. ([G:81D983B1](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-81D983B1-A719-4007-8A22-E26BE5A9C891))
- MEP runs on the AutoCAD core, so every AutoCAD command is available, but basic AutoCAD objects and building systems objects react differently to them (section 14). ([G:EA480FC5](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-EA480FC5-26C5-45E9-9B98-8FBAD7C11022))

### Connectors and domains
- Connector: a predefined point where properties (system, shape, size) pass to the connected object. All building systems objects have smart connectors: one (terminal, receptacle, water meter) or many (air handling unit, junction box). ([G:16ADED4B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-16ADED4B-13A1-47F2-8F99-06C3FFDFC16F))
- On connection the new object inherits system, elevation, shape and size from the object it joins. ([G:16ADED4B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-16ADED4B-13A1-47F2-8F99-06C3FFDFC16F))
- Each connector has a domain: the type of building system (HVAC, pipe, electric ...). One object can mix domains: an AHU is HVAC but carries a gas connector in the pipe domain and a power connector in the electric domain. Each domain has a fixed list of properties compared to validate a connection. ([G:16ADED4B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-16ADED4B-13A1-47F2-8F99-06C3FFDFC16F))
- Connector styles hold the rules: which properties are compared and whether the connection is allowed. Pipe to pipe normally needs the same size and the same system. A rule on connection type and domain keeps the wrong connection type off an MvPart. ([G:16ADED4B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-16ADED4B-13A1-47F2-8F99-06C3FFDFC16F), [G:E74B82AB](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E74B82AB-2FF8-4CD1-A401-6F774A53AC52))
- A connection is valid only if the parts are in the same system group AND the connector style rules are met. ([G:01DC838A](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-01DC838A-0C23-4DD8-9683-88A85A5CC2EF))
- [GUI] Connector style rules: Manage tab > Style & Display panel > Style Manager > Multi-Purpose Objects > Connector Styles > Rules tab. ([G:2405FE1C](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2405FE1C-059A-46B0-9779-C2B1DD939083))
- Catalog content follows "Rules for Connector Behavior"; style-based content uses Connector Styles (both topics are outside these notes). ([G:16ADED4B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-16ADED4B-13A1-47F2-8F99-06C3FFDFC16F))

### Basic workflow ([G:0F5DF631](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-0F5DF631-417C-416B-B4A9-FAC00947ADBD))
1. Set project-level parameters and document sets: standards, look of the drawing area and parts, tool catalogs; sheets, sheet lists, cover sheets.
2. Link the architectural floor plans as xrefs through Project Navigator.
3. Preliminary outlines: flow and 1-line diagrams with the schematic tools.
4. Detailed design with catalog parts and custom content (HVAC, electrical, plumbing, radiant heating, piping).
5. Circulate for review: Drawing Compare shows differences between revisions.
- Analysis: before design, model spaces and zones for heating and cooling loads and export gbXML; while drawing, instant sizing of duct or wire; after design, check loads and resize. ([G:6526DCB8](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-6526DCB8-DEBA-4C44-872B-8BFB91624FA9))
- Review preferences and system definitions BEFORE drawing. You can also draw with no setup. ([G:23ED7114](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-23ED7114-9620-41E5-97F9-983F47CBA9D2), [G:D562400D](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-D562400D-6E17-4E85-BFEB-DA5C18D8D7FB))

## 2. Scripting quick reference

General
- The notes give almost no hyphen (-NAME) forms and few full prompt lists for MEP commands. Treat a command marked "prompts not documented" as untested: run it once in a scratch drawing before scripting it.
- [AUTO] Command search in the application menu needs the Aecb prefix for MEP commands: aecbPipeAdd, not PipeAdd. The page does not say whether the command line needs the prefix. ([G:C4C54B64](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-C4C54B64-5775-4AA1-862B-3541F57EE6B4))

### Connection Test Mismatch ([G:C5BB7DCB](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-C5BB7DCB-9254-4A4E-B376-9242B576A7B9))

## 7. Systems, system groups and system definitions

### What a system is
- A system = a network of connected parts that stand for a real building system (duct, pipe, fittings, equipment; or conduit, wire, devices, panels). Parts in it share one look and feel. ([G:E7C4DBC8](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E7C4DBC8-ED10-4641-ACE8-F9F7C831A90F))
- A system stores properties held constant across all its parts. New parts inherit the CURRENT system's defaults (size, shape). Changes can apply to the whole network at once. ([G:E7C4DBC8](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E7C4DBC8-ED10-4641-ACE8-F9F7C831A90F))
- Define a series of systems at project start and keep them. Predefined systems follow industry standards; each has an abbreviation, layer keys and display properties. ([G:E7C4DBC8](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E7C4DBC8-ED10-4641-ACE8-F9F7C831A90F))
- Systems are style-based: manage them in Style Manager. ([G:E7C4DBC8](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E7C4DBC8-ED10-4641-ACE8-F9F7C831A90F))
- Electrical and plumbing systems also have a system type. Electrical type controls things like number of poles; plumbing type controls pipe sizing, fitting orientation and fixture connections. ([G:E7C4DBC8](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E7C4DBC8-ED10-4641-ACE8-F9F7C831A90F))
- Changing one segment's system updates every component with a valid connection to it. ([G:9EE97DB4](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-9EE97DB4-6044-47DC-B8B9-85AD48C247D7), [G:4CA2F84D](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-4CA2F84D-6632-410D-8F3B-5E5FE874B318), [G:2801A5D1](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2801A5D1-F63A-49B3-85A5-FB41554F4BD6))
- Changing the system on one connection can change the system of connected parts, depending on the connector style rules in the drawing. ([G:6B598B33](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-6B598B33-839B-4C03-8A02-FA52FECE3B68))
- Schematic lines and symbols also take systems; new ones inherit the current system's defaults (layer, color ...). ([G:CFEAE09A](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-CFEAE09A-E0CF-4F8F-9908-0F6AFDC46EEF))
- Where the system is set: the properties dialog for duct and MvParts; the Properties palette for pipe, conduit, plumbing. ([G:6B598B33](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-6B598B33-839B-4C03-8A02-FA52FECE3B68))

### System groups ([G:660EE061](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-660EE061-DEAF-4731-A117-916EAE307A90))
- A system group ties related systems so they can connect while each keeps its own properties and display. A group can hold any number of systems.
- Example: recirculating hot water (HWC) connects to supply hot water (HWS) because both definitions sit in one group (non-potable water); the run stays one connected pipe system.
- Systems NOT in the same group: when you connect them you are prompted to change the connecting run's system to match the receiving run. Decline: the right fitting is still inserted, but the systems are NOT connected; edits to the receiving system do not reach the connecting run.
- Dissimilar systems allowed to connect with no group = invalid connection (solution tip marker shows). Creating the group afterward turns those connections valid dynamically.
- Best created when the systems are created. Uses: one system per zone grouped as one heating supply; one per voltage grouped as one power supply; one per floor grouped as one sanitary waste.
- Duct example: Supply - High Pressure and Supply - Medium Pressure in one group connect and each keeps its own system. ([G:9EE97DB4](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-9EE97DB4-6044-47DC-B8B9-85AD48C247D7), [G:4CA2F84D](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-4CA2F84D-6632-410D-8F3B-5E5FE874B318), [G:2801A5D1](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2801A5D1-F63A-49B3-85A5-FB41554F4BD6))
- System Group field left blank = may connect to any system group. ([G:B8BFD4FD](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B8BFD4FD-3E01-490F-8693-1328A0671252))

## 8. Objects

### Object essentials ([G:E63ED223](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E63ED223-BF7D-488A-8C6C-41FC0C055E30))
- Layouts are built from objects that stand for real parts: duct, cable tray, pipe segments, fittings, equipment, devices, panels, fixtures. Every part has an object type, which drives how it is drawn, how it behaves and which display representations apply.
- Block-based parts: one instance with predefined properties (shape, size), built from a set of AutoCAD blocks, one per view, so the look changes with view direction.
- Parametric parts: generated on demand from predefined or user-defined properties as 3D model blocks; the look also changes with view direction.
- Parts can have behaviors (automatic cleanup when connecting; default insertion in some situations) and several components (centerline, insulation, lining).

### Object types ([G:58B39CF1](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-58B39CF1-38D7-4319-9A07-343A7A6B3619))
- Segments (Cable Tray, Conduit, Duct, Pipe): generated from predefined properties; other parts connect to them; trimmed when fittings connect. Components: connector, annotation, centerline, rise/drop. Duct and pipe add contour, insulation, lining.
- Fittings (Cable Tray, Conduit, Duct, Pipe Fitting): generated from predefined properties; the software inserts them during run layout. Same components as their segment type.
- Duct Custom Fitting, Pipe Custom Fitting: generated from a centerline built from user-picked AutoCAD lines and arcs.
- Flex Duct, Flex Pipe: predefined properties plus ONE user-defined centerline; components contour, connector, annotation, centerline, insulation, lining, rise/drop.
- MvPart: parametric or block-based; looks different per view and display representation; one or more connection points; used for equipment (air terminals, fans) and fixtures (lavatories, toilets).
- Device, Panel: style-based; shown as one of several predefined blocks per display representation and view direction. Wire uses them to complete connections.
- Wire: style-based; annotation styles for crossings and connections; cleans up as it connects.
- Circuit: non-graphical connection between electrical components (system, rating, panel, number of devices, length, poles, voltage, total load, demand factor, estimated demand load).
- Label Curve: style-based; uses attributes to read part info; anchored to its part but editable on its own.
- Plumbing Line: style-based; keeps flow direction, slope, elevation, fixture unit load. Plumbing Fitting: style-based, insertable during layout.
- Schematic Line: line for connectivity and logic (system, designation, ID). Schematic Symbol: block for real equipment or parts; breaks into a line or attaches to a line end.
- Devices and lights show as symbols in plan; lights are scaled to their real envelope. Electrical MvParts show real geometry to scale. ([G:45362B94](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-45362B94-760D-44EB-A9EF-FE945D676BE0), [G:031F9C4D](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-031F9C4D-0BC2-4D3D-918A-00B5F4F08452))

- [GUI] Properties palette > Placement > Justification: Top / Middle / Bottom crossed with Left / Center / Right (9 values), plus typed horizontal and vertical offsets. Uniform offset from the picked points = enter both offsets.
- Draw direction = connector 1 (start) to connector 2 (end); it decides how Left and Right show.
- Starting from a fitting connected to a segment applies that segment's justification; otherwise the last used justification applies.
- AutoCAD MIRROR adjusts justification to each object's orientation (one Top Left, its mirror Top Right).
- Offset runs: Properties palette > Placement > Justification horizontal offset (same elevation, + = positive X/Y) or vertical offset (same X-Y, + = +Z), then pick points on existing geometry, including xref geometry. ([G:2662D03D](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2662D03D-907F-40A3-A837-C6B93E0627BE), [G:A2F7AF29](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-A2F7AF29-3741-4E7F-9442-4C4361814A54))
- 2026 and later: Placement > Top Elevation and Bottom Elevation on conduit, duct and pipe; move and edit by top or bottom. A conduit on the ground has Bottom Elevation 0. ([G:3ECB60FA](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-3ECB60FA-EC51-49BB-8406-2074CA2C7482))

## 14. Moving from AutoCAD to AutoCAD MEP

### What MEP adds ([G:A011A47B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-A011A47B-FCD3-4CC4-9BD2-A7ECF63FE291))

  - Connection-aware: COPY, MOVE (selection sets), BREAK at one point, FILLET (plumbing and schematic lines), OFFSET (one segment).
  - Safest per the pages: Add, Location, Rotate, Lengthen and Alignment grips with MEP snaps and polar tracking.
- (inference) For scripts: prefer COPY and MOVE of whole selection sets over STRETCH or ALIGN, never EXPLODE the working file, and check connectivity after each edit batch (section 13).

## 17. Glossary of MEP terms
- 1-line / 2-line: single-line or double-line display of duct and pipe. 1-line duct is an undefined placeholder route (shape and connection type Undefined) that the duct size calculator turns into sized 2-line duct. ([G:303F3BD3](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-303F3BD3-216A-4879-AB22-2C5D22758ABE))
- Add grip: grip that starts or extends a run with guaranteed connectivity; on an elbow it turns the elbow into a tee. ([G:73D20042](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-73D20042-79CD-40E3-B515-AE94BABEB76D), [G:44FA15E5](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-44FA15E5-00AB-4AB5-B228-BEA94E9671D1))
- Alignment grip: device and panel grip that moves the item and turns it square to a wall or other snapped object. ([G:E9453F0B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E9453F0B-B866-41BD-BA74-CEAFA12C5132))
- Anchor: link between building systems objects. Curve anchor (to a host centerline), system anchor (anywhere on runs of one system), reference anchor (by reference; the host follows). ([G:B0888C4D](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B0888C4D-80D6-425B-9C84-BD4E18F07F59))
- APC: Autodesk Part Catalog file extension. ([G:3D87EBEC](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-3D87EBEC-1999-47D3-A504-613F02980DB0))
- Associative movement: moving or stretching connected objects without breaking connections. ([G:FBAC8FEC](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-FBAC8FEC-3928-4A21-8E2F-033AB99B92E3))
- Block-based part: part built from a set of AutoCAD blocks, one per view direction. ([G:E63ED223](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E63ED223-BF7D-488A-8C6C-41FC0C055E30))
- Catalog, chapter, part family, part size: a catalog holds chapter folders; chapters hold part families; a family stores its sizes; you insert one size. ([G:7686F1CF](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-7686F1CF-0A04-479A-87A7-B6E38978FAB4))
- Catalog Editor: tool to browse, edit and add catalog content. Content Builder: tool to build parametric or block-based parts. ([G:19546C46](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-19546C46-F201-4822-8963-F639FF96298C), [G:64884E3A](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-64884E3A-15B2-472E-B641-B72C425C8468))
- Circuit: non-graphical database element that connects electrical devices to a panel. ([G:4419EDDF](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-4419EDDF-DB88-4DE1-AC5B-90F082BF5C06), [G:58B39CF1](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-58B39CF1-38D7-4319-9A07-343A7A6B3619))
- Classification: user-defined values stored in a style, used to display and schedule objects; MvParts and fittings are classified automatically (Air_Terminal ...). ([G:B07A7E8E](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B07A7E8E-8224-48C5-8A9D-05F3E3E0673F))
- Compass: on-screen guide for run direction, angle snap and tick marks; p switches the UCS plane. ([G:9F8199F2](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-9F8199F2-616E-4458-9CAA-D77BC4396DFE))
- Connector: point on an object where system, shape and size pass to the connected object. End connector = object end; curve connector = anywhere on the centerline. ([G:16ADED4B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-16ADED4B-13A1-47F2-8F99-06C3FFDFC16F), [G:AE10A92A](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-AE10A92A-C3A1-4CDD-BC08-70CD417C718C))
- Connector style: rules on which connector properties must match for a valid connection. ([G:16ADED4B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-16ADED4B-13A1-47F2-8F99-06C3FFDFC16F), [G:E74B82AB](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E74B82AB-2FF8-4CD1-A401-6F774A53AC52))
- Construct, view, sheet: Project Navigator drawing types: the 3D model, a view of it at one scale, and the plot sheet. ([G:7B2F5167](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-7B2F5167-E1B6-4D37-947C-56BE78A90E73))
- Content Browser: catalog of tools and palettes (MEP Stock Tool Catalog ...). ([G:647085B2](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-647085B2-580A-43FB-8E82-1F96599E58A7))

- DDXML / DuctXML: duct network exchange format for external duct sizing tools. ([G:2D49B3DF](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2D49B3DF-7B7A-4D85-BBA9-45B055D3A833), [G:A7B0C678](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-A7B0C678-8890-4F80-9B4C-F47772F76504))
