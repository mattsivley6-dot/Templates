# 08 - Construction Documents I: MEP Annotation, Tags, Labels, Flow Arrows, Elevation Labels, Keynotes, MV Blocks, Anchors and Fields

Adapted from Autodesk AutoCAD 2027 help (help.autodesk.com), (c) Autodesk, Inc., under CC BY-NC-SA 3.0. Condensed, reorganized and annotated with test notes. See [LICENSE.md](LICENSE.md).

Citation legend: `G:` links go to Autodesk help pages; `KB:` links go to Autodesk support articles (linked and summarized, not copied); codes with no link have no public URL on file.

How AutoCAD MEP 2027 drawings get annotated and checked before they go on sheets.
Tags attach property set data to parts and feed schedules. Labels and flow arrows read object properties along ducts, pipes and other curves. Elevation labels, keynotes, annotation symbols, AEC dimensions and fields complete the set.
Multi-view (MV) blocks and anchors are the AEC objects that tags and symbols are built on. Interference detection and the connection checks find layout errors.
The last parts are an AEC command reference with prompts, sorted for scripting.
Schedule table styles, sheets, views and publishing are only touched where annotation depends on them (they belong to Construction Documents II).

Source note: many pages cited here are AutoCAD Architecture 2027 help (book AutoCAD-Architecture). MEP runs on the same AEC platform, but those pages never say which commands exist in MEP. Type the command name at the MEP prompt before building a script on it.

### Practical rule (inference)
A script can place objects, answer prompt keywords and set variables. Anything chosen in a worksheet (tag values, a keynote, a field) needs a preset default on the tool or property set definition, or another route. Two preset routes are documented: a PSD manual property default value ([G:1EE615FE](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-1EE615FE-74A9-435A-B129-CEE34C148015)), and a keynote tool whose field names one fixed keynote instead of acting as a placeholder ([G:658402D8](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-658402D8-70D2-413F-9F4D-E5762142FB76), [G:A8252C38](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A8252C38-1DDA-47D5-943F-4008A33FEA19)).

## 8.2 Tags and the property set data they carry

### What a tag is and does
- Main job: attach property set data to a part. After tagging, equipment schedules for that part type fill from the chosen property set data. Second job: annotate the part (example: a tag on a ceiling diffuser showing its airflow). ([G:0046C357](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-0046C357-5B5E-436A-B951-82D60EE3277D))
- Equipment must be tagged before it can be scheduled. Adding a tag adds the property set definitions (PSDs) tied to that tag to the part. ([G:B842CB52](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B842CB52-C0E4-404A-AC2C-41361A392DE0))
- Values are either automatic, read from the part (example: connection size), or manual, typed by hand (example: manufacturer). ([G:0046C357](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-0046C357-5B5E-436A-B951-82D60EE3277D))
- The available property sets come from the PSDs assigned to the tag tool. ([G:1D9664E1](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-1D9664E1-943C-420F-9370-D259C194158C))
- A schedule tag is a multi-view block ([KB:000634243](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-change-the-text-size-for-AEC-Tags-and-other-annotation-objects-for-a-specific-scale-style-in-AutoCAD-Architecture-or-MEP.html), [G:8BF72B71](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-8BF72B71-D673-4A19-961C-CE6F6AB42140)). Each attribute in it is named from the PSD name plus the property name (the attribute tag). When the tag is anchored to an object that carries that PSD, the attribute shows that property's value. ([G:D0E1DB35](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-D0E1DB35-2E54-442F-9533-2CC8FE52D1BC)) Example attribute name: `ECDuctSystemData:BODTOD_OffsetTag`. ([KB:000635992](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Labels-and-tags-shrink-or-change-size-when-moving-MEP-objects-ducts-in-Elevation-view-in-AutoCAD-MEP.html))
- A property used by schedule tags must have NO spaces in its name. ([G:FC65DF0E](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-FC65DF0E-0EB2-46B2-9F09-567BEC7ADC83), [G:1EE615FE](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-1EE615FE-74A9-435A-B129-CEE34C148015))

### Anchoring
- A tag is anchored to its part. Move the part and the tag follows. The tag can be moved alone without releasing it. ([G:B842CB52](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B842CB52-C0E4-404A-AC2C-41361A392DE0))
- A tag copied to another object stays anchored to the ORIGINAL object. Re-anchor [GUI]: select the tag > Tag tab > Anchor panel > Set > pick the new object. ([G:EAD45174](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-EAD45174-FDBF-439D-B97E-D2375FCFAB41))

### Add a tag (MEP procedure) ([G:B842CB52](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B842CB52-C0E4-404A-AC2C-41361A392DE0))
1. Tag and Schedule tool palette > pick a tag tool. Or Annotate tab > Scheduling panel > Tags drop-down > pick a tag. [GUI]
2. Select the object to tag. [AUTO pick]
3. Tag location: press Enter to center the tag on the part, or click a point. [AUTO]
4. Edit Property Set Data dialog: type the editable values. Automatic fields are gray and read-only. [GUI]
5. OK.
6. Next part: pick another object and repeat, or type `m`, select more objects of the SAME part type, press Enter. Each new tag gets the same relative location and the same property set values as the first. [AUTO]
7. Enter ends the command. [AUTO]
- ACA wording of the same flow: pick tag tool, select object, specify location; prompts differ per tag; fill the worksheet "if prompted"; for several objects "type m, Enter, select the objects". ([G:120058F4](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-120058F4-8919-4CA4-AC60-7A2DB83930CF))
- Tag data that belongs to a system style or object style may be inactive in the dialog. Edit it afterward in the Properties palette. ([G:B842CB52](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B842CB52-C0E4-404A-AC2C-41361A392DE0))
- Usually tag after the parts are placed. Electrical devices can be tagged automatically as they are added. ([G:B842CB52](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B842CB52-C0E4-404A-AC2C-41361A392DE0)) Device tool properties can name property sets and tags so they attach on insertion. ([G:BC28B896](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-BC28B896-8D5C-464C-8542-D8892C48DA14))
- If the object has no property set data yet, the ACA tag flow can attach a set from the current drawing or from Schedule Tables.dwg in `C:\ProgramData\Autodesk\ACA <version>\enu\Styles\<Imperial or Metric>`. ([G:120058F4](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-120058F4-8919-4CA4-AC60-7A2DB83930CF))
- Project-based tags (structured project) read extra object information when you tag objects in view drawings. ([G:120058F4](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-120058F4-8919-4CA4-AC60-7A2DB83930CF))

## 8.5 Labels and flow arrows

### What labels are
- Labels are text or block definitions whose content comes from object properties (example: connection size). They anchor to objects; moving a label does not detach it. Autodesk recommends adding labels in construct drawings. ([G:5D092C56](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-5D092C56-A218-4367-BB02-7FA5B5E61F57))
- Labels can go on ducts, pipes, plumbing lines, wires, cable tray, conduit and schematic lines. ([G:DC82CA79](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-DC82CA79-7FA5-455B-A730-730373080D08)) The add-label task pages for duct and pipe ("To Add a Label or Flow Arrow to an Existing Duct", "To Add Labels or Flow Arrows to Pipe") are named but not in this section's sources. ([G:DC82CA79](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-DC82CA79-7FA5-455B-A730-730373080D08))
- A label attached to a pipe updates automatically when the parent object changes. ([G:AF3D7CB8](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-AF3D7CB8-A44F-4526-82BA-A11FDC1EF214)) Contrast: DesignCenter elevation labels do NOT update (8.6).
- Labels show system name, size and dimensions; they and documentation symbols are the primary annotation. ([G:4F1AACFC](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-4F1AACFC-1D7A-46B9-8FEE-C346701F96D1))

### Edit a placed label or flow arrow ([G:AF3D7CB8](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-AF3D7CB8-A44F-4526-82BA-A11FDC1EF214)) [GUI]
- Grips (select the label to show the pipe grips):
  - Add grip: adds a label. Ctrl+click adds labels at even spacing.
  - Location grip: move the label along the curve. Press Ctrl after clicking it to offset the label from the curve.
  - Repeat Distance grip: click along the curve to set a distance from the curve start; labels repeat at that distance. Ctrl+click it to space labels evenly.
- Ribbon, Label tab: General panel > Add Selected drop-down > New Label Node (pick a point on or near the object). Modify panel > Delete (remove a node); Offset (enter a distance, Enter; one label or all labels in the drawing); Rotate (rotation point, then value; one or all); Move To Object (anchor the label to a different object).
- Properties palette > Design tab > Dimensions > layout method: One by one; By distance (enter a distance); By quantity (enter a number of labels). The page's table rows pair "evenly spaced" with By distance and "repeated spacing value" with By quantity, which reads swapped (inference). The label style is changed on the same palette.

Ribbon: select a label > Label tab > General panel > Edit Style > Label Style dialog. Tabs: General, Label Style Annotation, Label Style Offset. ([G:D8C4C744](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-D8C4C744-5F14-404A-B6B6-8D62931696C6), [G:CBB55B41](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-CBB55B41-810E-40F3-B53D-F9BF61635FA0))

### Label Style Annotation tab: content options ([G:CCF59C17](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-CCF59C17-9C8B-419C-A175-3D7F55B708DA))
- Use Block graphics: a chosen block plus a scale factor. "Use Annotation Scale for Block" makes it follow annotation scale; that check, not the block's Annotative property, decides whether the style is annotative.
- Use Objects Properties: mechanical = prefix, suffix and symbol with the dimensions of duct, pipe and fittings; electrical = same for cable tray, conduit and fittings; wire = panel name if it has a home run, else circuit number; devices = ID; panels = panel name; plumbing = dimensions of plumbing lines and fittings; MvParts = properties of the closest connector; schematic symbols = ID; schematic lines = designation.

### Label Style Offset tab ([G:694EB7A2](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-694EB7A2-19FA-4A74-AA15-C7DA501D1A8C))

### Label text size and annotative behavior ([G:32BCA5AF](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-32BCA5AF-AA85-4CAE-B3AB-7429BB0E5DEA))
- A label is annotative only if its label curve style is annotative.
- Block or flow arrow graphics: annotative when "Use Annotation Scale for Block" is checked in the style (it is auto-checked when you pick a block whose Annotative property is Yes; you may uncheck it). Editing the Annotative property inside the block definition does NOT switch a block-based style.
- Text-based style, the text style decides:
  - Annotative on or off, Paper Text Height (or Height) = 0: label size = annotation plot size (Drawing Setup) x current annotation scale.
  - Annotative on, height > 0: Paper Text Height x current annotation scale.
  - Annotative off, height > 0: the Height value; the label curve style is NOT annotative.
- Switching a style between annotative and not updates every label using it.
- Label text does not match other annotation ([KB:000449429](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Adjusting-text-size-for-Label-Curve-objects-in-AutoCAD-MEP.html)): give the style a non-annotative text style with Height > 0 (STYLE, then Label Style Annotation tab > Text Options), or set Scale and Annotation Plot Size in AECDWGSETUP > Scale tab when the text style has no Paper Text Height.

### Labels that show property set values or sizes
- Show an Extended Data property (example: Elevation): make a label curve style (Style Manager > Documentation Objects > Label Curve Styles) and on its Label Style Annotation tab choose Use Property Set, then the PSD and the property. Prefix and suffix come from Dimension String Options or from the Property Data Format. ([KB:000544992](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-annotate-existing-properties-of-MEP-objects-in-AutoCAD-MEP.html))
- FIELD in MText cannot reach the size (length, width, diameter) of ducts, duct terminals, pipes or cable trays; they are not object properties available to FIELD. Use the labels on the Annotation tab of the matching tool palette. ([KB:000342364](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-annotate-size-of-MEP-objects-in-AutoCAD-MEP.html))
- Numeric precision: make a Property Data Format with the precision, a PSD with a Formula property that holds the numeric property and uses that format, then set the label style to Use Property Set with that formula property. Or change drawing precision with UNITS, which changes every displayed value. ([KB:000532202](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/To-change-the-annotation-format-of-Labels-for-numeric-properties-like-size-in-AutoCAD-MEP-and-Architecture.html))
- Duct labels and tags that shrink in Isolate > Edit in Elevation: see 8.6. ([KB:000635992](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Labels-and-tags-shrink-or-change-size-when-moving-MEP-objects-ducts-in-Elevation-view-in-AutoCAD-MEP.html))

## 8.7 Annotation scaling for MEP objects

### Current annotation scale
- [AUTO] CANNOSCALE sets the current annotation scale for the current space (model space or a paper space viewport). ([G:3F7F41E4](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-3F7F41E4-14EB-4D18-9C50-223EE6A5B799), [G:017F80EA](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-017F80EA-AF4B-4CD2-A374-9EAF103A7E5B))
- One annotation scale for model space and one per paper space viewport; saved with model views. ([G:E2B3F528](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E2B3F528-1044-48C5-8797-35D7B9E7BD69), [G:017F80EA](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-017F80EA-AF4B-4CD2-A374-9EAF103A7E5B))
- In paper space, viewport scale and annotation scale are synchronized when the scaling controls are used. Zooming with the mouse wheel or Zoom commands changes the view only; the annotation scale does NOT change. ([G:3F7F41E4](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-3F7F41E4-14EB-4D18-9C50-223EE6A5B799), [G:4335105B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-4335105B-F200-4FC7-A5B7-EA9205C2BC4E))
- [GUI] Model tab or selected viewport > status bar annotation scale flyout. Model space scale is also on Drawing Setup > Scale tab. ([G:3F7F41E4](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-3F7F41E4-14EB-4D18-9C50-223EE6A5B799))
- Size formula: Object Height x Annotation Scale x Annotation Plot Size = model or paper space height. Example: viewport 1/4" = 1'-0", object height 1: 1 x 48 x 1/4" = 12" model-space text. ([G:4335105B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-4335105B-F200-4FC7-A5B7-EA9205C2BC4E))

### What scales in MEP ([G:32BCA5AF](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-32BCA5AF-AA85-4CAE-B3AB-7429BB0E5DEA), [G:E2B3F528](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E2B3F528-1044-48C5-8797-35D7B9E7BD69))
- Annotative objects follow the current annotation scale only if they have a scale representation for it; otherwise they draw at the scale they were created in. Annotative components inside non-annotative MEP objects ALWAYS follow the current annotation scale. ([G:E2B3F528](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E2B3F528-1044-48C5-8797-35D7B9E7BD69))
- Annotative components of non-annotative MEP objects:
  - All domains: rise and drop symbols; MvPart view blocks if Use Annotation Scale is checked per view in the MvPart style (Views tab, Style Manager).
  - HVAC: flow markers; flex duct annotation pattern; air terminal flow arrows if Use Annotation Scale for Block is checked (Flow tab, Multi-view Part Properties dialog).
  - Piping: flow markers; flex pipe annotation pattern; placeholder pipe; in Graphical 1-Line: rise and drop symbols, in-line and anchored MvParts, reducers.
  - Electrical: home runs, tick marks, wire gaps; cable tray pattern; device and panel view blocks if Use Annotation Scale is checked per view in the style.
  - Plumbing: plumbing fittings (always follow in model space); gaps on plumbing lines.
  - Schematic: schematic symbols (always follow in model space); start, end and connection symbols and gaps on schematic lines.
- For block-based components (air terminal flow arrows, device view blocks) the Use Annotation Scale (for Block) check decides; the block definition's Annotative property does not matter.
- NOT annotative: the Hatch display component; schedules (a schedule keeps the annotation scale that was current when it was inserted).
- Other annotative objects: MV blocks, AEC dimensions; AutoCAD text, mtext, dimensions, leaders, blocks, hatching, linetypes.
- How to check one object [AUTO]: run LIST on it and read the Annotative value, or hover for the annotative icon (several shapes = several scale representations). ([G:32BCA5AF](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-32BCA5AF-AA85-4CAE-B3AB-7429BB0E5DEA))
- [AUTO] MSLTSCALE = 1 scales model space linetypes by annotation scale; PSLTSCALE = 1 scales paper space linetypes by viewport scale. ([G:32BCA5AF](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-32BCA5AF-AA85-4CAE-B3AB-7429BB0E5DEA))

### Scale representations ([G:6490C21B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-6490C21B-1DB3-4B6E-833E-50C18B851218), [G:2ADC144E](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2ADC144E-4F57-4AC2-888B-756508470564))
- A new annotative object supports only the annotation scale current when it was added. Add more: select > right-click > Annotative Object Scale > Add Current Scale (or the Annotative Scale panel of the context menu). ([G:2ADC144E](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2ADC144E-4F57-4AC2-888B-756508470564), [G:6490C21B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-6490C21B-1DB3-4B6E-833E-50C18B851218))
- Non-annotative objects with annotative components (devices, air terminals) have no scale representations. ([G:6490C21B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-6490C21B-1DB3-4B6E-833E-50C18B851218))
- [AUTO] ANNOAUTOSCALE: when on, changing to a scale adds that scale representation to ALL annotative objects, xrefs included. Keep it off in a multi-scale model space drawing. ([G:6490C21B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-6490C21B-1DB3-4B6E-833E-50C18B851218))
- DANGER: using that auto-add on annotative objects in an xref made in an earlier release upgrades the xref file to the current format; the older release can no longer open it. ([G:6490C21B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-6490C21B-1DB3-4B6E-833E-50C18B851218))
- Values used in the support articles: ANNOAUTOSCALE = -1 for off ([KB:000517153](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/To-use-conditional-statements-in-formulas-for-annotation-with-leader-in-AutoCAD-Architecture-or-MEP.html)); = 1 to push a new scale onto all annotative objects ([KB:000634243](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-change-the-text-size-for-AEC-Tags-and-other-annotation-objects-for-a-specific-scale-style-in-AutoCAD-Architecture-or-MEP.html)). The help page gives no value table.
- [AUTO] ANNOALLVISIBLE: show only annotative objects that support the current scale, or all of them (status bar buttons). Objects lacking the current scale then draw at their creation scale. Devices and air terminals (annotative components) are always shown and cannot be hidden with it. ([G:2ADC144E](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2ADC144E-4F57-4AC2-888B-756508470564)) The page gives no values; standard AutoCAD uses 1 = all, 0 = only supporting (inference, verify).
- Grips: labels and AEC dimensions have ONE Location grip for all scale representations. Annotative MV blocks have TWO (all scales; current scale only). Other annotative objects have one Location grip per representation; use MOVE to move them in all scales. ([G:6490C21B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-6490C21B-1DB3-4B6E-833E-50C18B851218))
- Annotation that jumps between scales: each representation stores its own position. [AUTO] ANNORESET resets all representations to the location of the current one. Prevent it by moving with MOVE after a window, crossing or pickbox selection, not with grips. ([KB:000258636](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Annotative-block-moves-when-annotation-scale-changed.html))

## 8.8 Annotation symbols and the basic annotation tool

### DesignCenter annotation symbols (MEP) ([G:86810BCD](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-86810BCD-C700-4078-B3CD-E92AB23DBF29)) [GUI]
- Documentation symbols: elevation labels, chases, revision clouds, match lines. Design symbols: electrical, mechanical and plumbing equipment.
- Design symbols are AutoCAD MV blocks. They do NOT connect to MEP objects; they are annotation only.
- Path: Insert tab > Content panel drop-down > Design Center > AEC Content tab > Custom Applications > AutoCAD Architecture 2027 toolset > imperial or metric folder > Design or Documentation > subfolders; drag a symbol from the right pane into the drawing; give location and orientation. Drag a symbol onto a tool palette to make a reusable tool.
- DesignCenter tools do NOT produce objects that respond to annotation scaling; the palette annotation tools do. ([G:BFF2F4E2](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-BFF2F4E2-10E4-4E06-A3A6-F1D54D782231))

### The basic annotation tool ([G:FC8FB184](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-FC8FB184-C573-4E71-A99B-E8C67A8BB4BA))
- One configurable tool makes multiline text notes (with or without leaders), symbol-based notes with attributes, reference keynotes, sheet keynotes and break marks. Type and look are set on the tool's Tool Properties worksheet (tool context menu). Objects are created at the current annotation scale. [GUI setup]
- Text-based (Content type Mtext) is generally used for reference keynotes; block-based (Content type Block) for sheet keynotes.
- Defaults live on the sample Annotation tool palette, the Stock Tool Catalog and the Documentation Tool Catalog (Content Browser); i-drop a tool onto a palette to customize it.
- Tool properties:
  - General/Layer key: default ANNOBJ. Layer override.
  - Multileader style: Text, Block or Standard.
  - General/Content type: Mtext or Block. With default Mtext settings you are prompted for text width at insertion.
  - General/Symbol and Symbol location (Block only): the symbol block and the drawing that holds it; blank (--) lists only blocks in the current drawing.
  - Leaders/Leader type: None, Straight, Spline. Leader dimension style: blank = current drawing's dimension style (arrowhead and text options). Limit points / Maximum points: leader points before the text or symbol goes in; blank = drawing's leader setting.
  - Text/Default text (Mtext only): blank for plain notes typed at insertion; a placeholder keynote field for reference keynotes.
  - Text/Angle: default Force horizontal; also As inserted (angle of the last leader segment) and Right reading.
  - Text/Prompt for width; Always left justify; Left side attachment; Right side attachment; Underline bottom line; Frame (Mtext with leader). Blank = drawing's leader setting.
  - Text/Mask background (Mtext): default No.
- Leader arrow size comes from the current dimension style and the drawing scale (Drawing Setup > Scale tab). ([KB:000308555](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Arrow-size-of-leader.html))

### Where each annotation object gets its annotative property ([G:8BF72B71](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-8BF72B71-D673-4A19-961C-CE6F6AB42140))
- MText made by the annotation tool, and leaders made by annotation, callout, detail mark or title mark tools: from the Leader Dimension Style tool property.
- Blocks made by those tools: from the block definition.
- MV blocks made by the MV block tool or the schedule tag tool: from the block definitions. MV blocks from DesignCenter content or command tools: none, but annotative can be set on their view blocks.
- AEC dimensions: from the AutoCAD dimension style named in the AEC dimension display properties.

## 8.9 Keynoting

All keynote pages are AutoCAD Architecture help; MEP uses the same tools and databases (per the platform note at the top).

### Concepts
- Two methods: reference keynoting (the key matches a specification section and can appear on many sheets) and sheet keynoting (keys numbered sequentially per drawing). ([G:AACE290E](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-AACE290E-CF06-4947-9A17-5C79BD7A00A6), [G:76D44ED7](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-76D44ED7-1CD7-424D-8EB7-43DF7BFA3AA6))
- Keynotes link to a keynote database, so they change globally or one at a time. They update automatically when the DATABASE entry changes; they do NOT update when the keynoted OBJECT changes. Use Re-Keynote for that. ([G:AACE290E](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-AACE290E-CF06-4947-9A17-5C79BD7A00A6))
- Display formats: key only, note only, or key and note (with a separator style such as "key - note" or "key:note"). Keys only needs a legend. ([G:2D594315](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-2D594315-600E-4ACC-A8E0-DA4124B4845A), [G:760DD5AC](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-760DD5AC-3940-47C6-9E17-E93BD3E84179))
- Pre-specified keynotes can sit at four levels: object (style), object component (material definition), 2D section/elevation linework, detail component. ([G:06F664A6](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-06F664A6-11C9-4E3F-B9BE-9794780E1A36))
- Only the KEY is stored with an object style; the NOTE text is fetched from a database at insertion. ([G:173620D4](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-173620D4-0C5A-4602-83D7-E4D878F652D1))

### Databases
- Keynote databases are Microsoft Access files (*.mdb). ([G:93D2930F](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-93D2930F-C5AA-43FA-A6A9-C437A65C3223), [G:5D98F4DE](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5D98F4DE-AB92-4B15-8239-2ACAD87EC93A)) Shipped: AecKeynotes (detail components and materials, CSI MasterFormat 2004) and AecKeynotes-Assemblies (assemblies such as an 8" CMU wall, CSI Uniformat). ([G:CB27848B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-CB27848B-B875-4D53-923F-741608AC18FB), [G:AACE290E](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-AACE290E-CF06-4947-9A17-5C79BD7A00A6)) Both are architectural; an MEP office would build its own (inference).
- Global list [GUI]: Options > AEC Content tab > Keynote Databases > Add/Remove > Add > pick the file > OK twice. New entries go to the bottom; Move Up / Move Down sets the search order; the top entry is the default in the Select Keynote dialog. Removing the top entry makes the next one the default. ([G:1804ECA5](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-1804ECA5-F4A0-4188-B459-3B6493C6C76C), [G:8AA0800B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-8AA0800B-8954-4359-B7EB-7DAD8CC9DF01))
- Projects: a database must be on the global list before a project can use it; inside a project, only the project's databases show in Select Keynote. ([G:173620D4](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-173620D4-0C5A-4602-83D7-E4D878F652D1))
- Keynote Editor [GUI]: Annotate tab > Keynoting panel > Keynote Editor (a standalone application, also on the CAD Manager menu). Buttons: New Database, Add Group, Add Keynote, Edit, Delete, Specify Keysort, Save. ([G:B1FC0645](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-B1FC0645-B2E9-4344-ABDF-FDD539EB54AA), [G:F8FC0EF2](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-F8FC0EF2-7441-4BB9-ADCF-3ACFC7879485)) Toolbar icon names are lost in the page text ([G:F8FC0EF2](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-F8FC0EF2-7441-4BB9-ADCF-3ACFC7879485)).
  - New Database: pick folder and file name; then the database properties button sets display name, description, author; result is a blank Access database with all keynote tables and a GUID. ([G:5D98F4DE](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5D98F4DE-AB92-4B15-8239-2ACAD87EC93A))
  - Add Keynote: select the group node > Add > key and note (ID field is read-only). Copy Series: right-click a keynote > Copy Series > number of copies; keys increment (A1001 + 10 copies = A1002 to A1011). ([G:F8FC0EF2](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-F8FC0EF2-7441-4BB9-ADCF-3ACFC7879485))
  - Deleting a group deletes its subgroups and keynotes; dragging a group moves its children too. ([G:02C6ACAC](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-02C6ACAC-B3EC-4E48-8F5F-4F7FF9E6676C), [G:3441B9E3](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-3441B9E3-C114-45BF-BFEF-81DA86AE7C9A))
- Schema for building a database in Access ([G:83DA22FB](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-83DA22FB-0F2E-4A1D-9BF7-29DE76F2E283)):
  - Fingerprint: GUID (generated on load through Add/Remove Keynote Databases if blank), Type (must be "Keynote"; "Component" = detail component database), Author, Display Name, Description.
  - Groups: ID (never change), Parent, Group (root parent is "-*" with ID 0), Description, Modified.
  - Keynotes: ID (never changes), Parent Group (assign "-*" to every keynote for a flat list), Key, Note, Modified.
  - KeySort: sort masks; record order = pattern order.

## 8.10 Multi-view blocks

### What they are
- A multi-view (MV) block is an AEC object that shows a different view block per view direction and per display representation. Each view block is an ordinary AutoCAD block. Many MV blocks can come from one definition. ([G:78B332E9](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-78B332E9-ECAE-44C6-B5F1-654F2F9D64F8), [G:72BDE4AD](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-72BDE4AD-8893-452B-8807-A5876820247D))
- Uses: furniture and fixtures, annotation components (revision cloud, fire rating sign), and schedule tags. ([G:78B332E9](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-78B332E9-ECAE-44C6-B5F1-654F2F9D64F8)) AEC tags are MV blocks. ([KB:000634243](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-change-the-text-size-for-AEC-Tags-and-other-annotation-objects-for-a-specific-scale-style-in-AutoCAD-Architecture-or-MEP.html)) MEP design symbols from DesignCenter are MV blocks that do not connect to MEP objects. ([G:86810BCD](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-86810BCD-C700-4078-B3CD-E92AB23DBF29)) Most MEP equipment is MvParts, a different object type with classifications and connectors. ([G:B07A7E8E](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B07A7E8E-8224-48C5-8A9D-05F3E3E0673F))
- Cutout use: a view block can act as an interference body subtracted from walls, slabs or curtain walls. ([G:78B332E9](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-78B332E9-ECAE-44C6-B5F1-654F2F9D64F8))
- Display representations for MV blocks: General (plan, section, sketch), Model, Plan, Plan High Detail, Plan Low Detail, Reflected. View directions: top, bottom, front, back, left, right, and Other (shown in 3D, used for isometric and perspective). ([G:CD4F3D00](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-CD4F3D00-3523-447A-AFC4-CFB8F9DEC319), [G:72BDE4AD](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-72BDE4AD-8893-452B-8807-A5876820247D))
- GOTCHA: assign a view block to EVERY view direction, or the MV block is invisible in some views. One block can serve several directions (tick Left and Right for a symmetric item). ([G:CD4F3D00](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-CD4F3D00-3523-447A-AFC4-CFB8F9DEC319))

## 8.11 Anchors

### Where anchors matter in MEP annotation
- A tag is anchored to its part ([G:B842CB52](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-B842CB52-C0E4-404A-AC2C-41361A392DE0)); a label is anchored to its object ([G:5D092C56](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-5D092C56-A218-4367-BB02-7FA5B5E61F57)); an interference tag is anchored to its interference mass element and is deleted with it ([G:BCF01DC7](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-BCF01DC7-7C06-4152-8618-D7A05F057C0D)); a copied tag stays anchored to the original object until re-anchored ([G:EAD45174](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-EAD45174-FDBF-439D-B97E-D2375FCFAB41)).
- A PSD "Anchor" property lets an object read data from the object it is anchored to (example: a door in a 2-hour wall shows the wall's rating). Read-only. ([G:25F2A859](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-25F2A859-A779-41BA-A734-F589CF8D063D))
- The anchor command and tool pages below are AutoCAD Architecture help (layout curves, grids, volumes). They apply to AEC objects in general.

### Concepts ([G:2C2F7003](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-2C2F7003-9D62-485F-A273-BDFB31A3E57F))
- An anchor links an AEC object to another object or to a layout curve or grid. AEC objects can be anchored to each other, to AutoCAD objects (lines, circles) or to layout curves and grids.
- Automatic anchors are set by the program (doors and windows to walls). A door anchored to a wall can move along walls but cannot stand alone until the anchor is removed.
- Six user anchor types: object (AEC to AEC); curve (to the base curve of lines, arcs, circles, mass elements, polylines, roofs or walls); leader (to nodes, with a leader); node (to nodes of layout curves or grids); cell (to cells of 2D layout grids or 3D volume grids); volume (to volumes of 3D grids).

## 8.12 AEC dimensions

AEC dimension pages are AutoCAD Architecture help. They list walls, openings, grids, mass elements, structural members, spaces, slabs, MV blocks and AutoCAD linework as dimensionable; they name no MEP object types (duct, pipe, MvPart). Test associative AEC dimensions on MEP objects before relying on them (inference).

### What they are
- Associative annotation objects that show measurements of building objects. Look comes from the AEC dimension style and can differ per view. Values are computed from the objects' current size and can be overridden by hand. ([G:AEC5D2CC](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-AEC5D2CC-5F5B-401B-AF5B-5A9E5956025F))
- Every AEC dimension style sits on an AutoCAD dimension style. The AutoCAD style controls color and lineweight of dimension and extension lines, arrowheads, text height and color, units, precision, decimal separator. The AEC style controls number of chains, dimensioned objects, distance between chains, fixed or variable extension lines, and opening height display. ([G:772B026D](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-772B026D-25A8-4C8F-B2FA-518ACE5A8A27))
- Up to TEN chains per AEC dimension style, each with its own points. ([G:80E8DF2E](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-80E8DF2E-1722-4957-BABF-910A0072EF81), [G:085E70B2](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-085E70B2-9AE9-4091-8341-C1EC4F8FAD2C))
- Associative dimensions work across xrefs, nested to any depth. ([G:A462AEE2](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A462AEE2-B593-403C-AA97-A72353B2CA30))

A field inserted directly in the drawing becomes an mtext element. ([G:76C68393](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-76C68393-2FC7-4203-862B-14C849E6BD4D), [G:A9EB91E9](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A9EB91E9-E570-474C-A957-B6B6D08E4FB4), [G:3AA08FF7](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-3AA08FF7-511B-4A62-AA97-BEA3564F63F3))

([KB:000342364](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-annotate-size-of-MEP-objects-in-AutoCAD-MEP.html))

## 8.15 Drawing checks and interference detection

### The five checking tools ([G:BAAFD81B](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-BAAFD81B-3E95-4556-B61C-78BF1EBC8064))

### Solution tips ([G:2405FE1C](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2405FE1C-059A-46B0-9779-C2B1DD939083), [G:E74B82AB](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E74B82AB-2FF8-4CD1-A401-6F774A53AC52))

- Ribbon [GUI]: View tab > MEP View panel > Solution Tips (turns icons on and off); Solution Tip Size (enter a size; the drawing regenerates). Hover an icon for the reason the connection is invalid.
- Icons stay until the connection is fixed AND the drawing regenerates.
- When they show: Options > AEC Editor tab > Solution Tip group: Drafting (while working) and Plotting/Publishing (when plotting or publishing). Clear Plotting/Publishing if icons must not print (inference).
- Valid connections keep size, shape, system type and part properties consistent. Connector style rules (Style Manager > Multi-Purpose Objects > Connector Styles > Rules tab) decide which properties must match, for example connection type and domain. ([G:E74B82AB](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E74B82AB-2FF8-4CD1-A401-6F774A53AC52), [G:2405FE1C](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2405FE1C-059A-46B0-9779-C2B1DD939083))
- Fixes: reshape with grips to connect to neighbors; change the object's system to match, or move it into the same system group; edit the connector style rules; delete the segment and redraw with MEP snaps. ([G:E74B82AB](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E74B82AB-2FF8-4CD1-A401-6F774A53AC52))

### Connected objects and connected runs
- [AUTO] CONNECTEDOBJECTS. Ribbon: Duct/Pipe/Wire etc. tab > Modify panel > Show Connected Objects drop-down > Show Connected Objects, then Enter. ([G:59872982](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-59872982-B95A-48B0-B84D-3BC4A43A70A9))

### Interference detection [GUI palette]
- Start: Analyze tab > Inquiry panel > Interference Detection. In the palette: under MEP Objects check the types to test; under Building Elements check the architectural and structural types; right-click either list for Select All / Clear All; Clearance Check yes/no, and if yes a clearance offset per object type; click Start Interference Analysis. No command-line form is documented. ([G:ADF10B78](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-ADF10B78-648F-4B1A-A178-B9CDAA220094))
- Scope: building systems vs building systems (duct vs pipe) and building systems vs architectural or structural objects (duct vs wall); current drawing, xrefs, or current vs xref. ([G:51735CAA](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-51735CAA-E033-4CB6-B5AB-484F51311918))
- Works only on 3D objects (MV block based or parametric). For plumbing it tests equipment and fixtures, NOT plumbing lines. ([G:51735CAA](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-51735CAA-E033-4CB6-B5AB-484F51311918))
- Hard clash = the geometry or 3D volume of two items intersects. Soft clash = the clearance space around an item intersects another; offsets can be set for pipe work, duct work, cable trays, conduits and hangers. ([G:51735CAA](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-51735CAA-E033-4CB6-B5AB-484F51311918))
- Highlight colors: red = hard, yellow = soft. Before running, recolor MEP objects and AEC structural members that are red or yellow, or use a display configuration made for clash work. ([G:51735CAA](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-51735CAA-E033-4CB6-B5AB-484F51311918))
- Each interference becomes a mass element at its location. Tolerance is computed to 5 decimal places. The analysis runs per drawing; switching drawings switches the palette. ([G:51735CAA](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-51735CAA-E033-4CB6-B5AB-484F51311918), [G:341B1300](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-341B1300-038F-4D3B-9C97-AF6D00B6CCCB))
- Review (Edit in Place tab > Interference Detection panel): sort by column heading; Activate Zoom To, then pick an item to zoom; Previous Interference / Next Interference; Zoom To toggle; "Select interference mass elements to highlight in interference list"; Hide Palette. ([G:A2705FBB](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-A2705FBB-7CD9-46F6-BBA0-C8395CB140A2))
- Deleting a mass element in the drawing does NOT remove it from the list. Fixed interferences are NOT removed automatically; rerun the analysis (it also catches clashes your fix created) or delete them by hand. ([G:A2705FBB](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-A2705FBB-7CD9-46F6-BBA0-C8395CB140A2))

([G:BCF01DC7](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-BCF01DC7-7C06-4152-8618-D7A05F057C0D)) Symbols and tags carry the size and elevation of each opening. ([G:4BA467DF](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-4BA467DF-3395-492A-B6C9-C5CF46BE4C74))
- Report [AUTO]: tag the interferences, then SCHEDULEADD; a default interference schedule ships with the product. ([G:4BA467DF](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-4BA467DF-3395-492A-B6C9-C5CF46BE4C74))
- Exit: End Interference Analysis. Mass elements made in the session and the tags attached to them are removed, unless Settings > "Keep interference mass elements when ending analysis mode" = Yes; to keep only some, delete the others first. Exit applies to the current drawing only; exit in each drawing analyzed. ([G:2394CB97](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2394CB97-E4FE-4A6E-B404-14E301813499))
- Conflict: [G:2394CB97](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2394CB97-E4FE-4A6E-B404-14E301813499) says inserted opening symbols REMAIN after exit; [G:51735CAA](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-51735CAA-E033-4CB6-B5AB-484F51311918) says tags and symbols are removed on exit unless you specify that they remain. Test before relying on either.
- [AUTO] COLLISIONDETECTION: turn on to show collisions in red while drawing; turn it off afterward to save system resources. ([G:2394CB97](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2394CB97-E4FE-4A6E-B404-14E301813499), [G:51735CAA](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-51735CAA-E033-4CB6-B5AB-484F51311918))
