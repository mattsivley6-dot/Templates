Summary:
- Drawing Management projects: Project Browser and Project Navigator, the APJ file and the XML file beside every project drawing, levels, divisions, constructs, elements, views, sheets, the project sheet set, publishing, eTransmit, repath, check in/out.
- Project Standards (standards drawings, versions, sync, audit, DWS/CHX), templates, the project tool palette group, the Content Browser and tool catalogs.
- Interoperability: EXPORTTOAUTOCAD and other ways to hand drawings to people without MEP, IFC, Navisworks, Revit, PDF/DWF/DWFx, STEP, Fabrication, LandXML.
- Drawing Management and Project Standards pages are AutoCAD Architecture 2027 help; the MEP 2027 toolset uses the same features ([G:E02A5760](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E02A5760-1412-44EE-BADB-1B1154AE1F5F), [G:E4420B66](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E4420B66-22D0-482A-9BA2-CA982B7278F6)). ## 10.1 Automation quick reference

### Project commands
- [AUTO] AECPROJECTBROWSER: opens the Project Browser dialog (blocks a script). Also Quick Access toolbar > Project Browser, or application menu Open > Project. ([G:5D27FC32](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5D27FC32-4B64-4B44-B75F-3B1A95D5FF0A)) Articles for 2013-2017 call it PROJECTBROWSER ([KB:000270076](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Refreshing-project-in-AutoCAD-Architecture.html)); 2021-2027 articles use AECPROJECTBROWSER ([KB:000608717](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Double-Clicking-a-Project-File-apj-Doesn-t-Launch-Any-AutoCAD-Architecture-Products.html)).
- [AUTO] AECPROJECTNAVIGATOR: shows the Project Navigator palette. It opens by itself when Project Browser closes. ([G:EE0034C0](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-EE0034C0-0708-4652-BD28-E4AABCFA5C49)) The toolbar icon runs `_AECPROJECTNAVIGATORTOGGLE` ([KB:000231172](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Project-Navigator-Palette-not-shown-in-AutoCAD-Architecture-or-MEP.html)).
- [AUTO] AECREFRESHPROJECT: refreshes the Navigator trees to the current project state. ([G:F63BE9A7](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-F63BE9A7-E108-49FA-8B96-9215507E5BE7))
- [AUTO] AECREGENERATEPROJECTVIEWS: regenerates every view drawing in the project; attaches, detaches or reloads the xrefs each view needs. Run after construct content, level or division changes. ([G:2D1066EC](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-2D1066EC-37D4-48A9-AA62-7AB38E4C01FD))
- [AUTO] VCOMPARE (page metadata AECVCOMPARE): compares the current drawing with another drawing. Opens the "Select Drawing File for Visual Compare" dialog, so it blocks a script. Enter leaves the result. ([G:03BCA989](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-03BCA989-C1B8-46FE-ADA0-6F9B15414A0D), [G:DBBF697C](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-DBBF697C-7B60-46E4-8D27-0CF765FD5356))
- [AUTO] AECVCOMPARENEWCOLOR, AECVCOMPAREOLDCOLOR, AECVCOMPAREUNCHANGEDCOLOR: value "R,G,B", integers 0 to 255, written 000,000,000. ([G:FC8A59B6](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-FC8A59B6-F26C-497F-A934-CF79222A4C36))
- [AUTO] AECVCOMPAREIGNOREHATCH, AECVCOMPAREIGNORETEXT: ON or 1 = ignore those differences, OFF or 0 = include them. ([G:349D546D](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-349D546D-E87F-4A48-BA28-88D69B0ADC3D))
- [AUTO] AecFileOpenMessage: set No to stop the previous-version dialog during a batch resave; set back to Yes after. ([G:46DF786B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-46DF786B-412F-4925-81F4-462E088DFE58))
- No command-line form is documented for New Project, Set Project Current, Move, Rename, Repath, Project Properties, new construct/element/view/sheet, Place on Sheet, Import Layout as Sheet, Insert/Update Sheet List, Resave All Sheets, or eTransmit from the palette. They are right-click and dialog actions. ([G:37FD55CE](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-37FD55CE-D564-4E7F-8879-60D007FD6327), [G:5DF55C84](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5DF55C84-541F-4A6E-8703-69DC13C646FD), [G:7D18FB7F](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-7D18FB7F-0BB0-41C5-8919-0E02364C3837), [G:0EFBBA99](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-0EFBBA99-5284-4863-A075-003E71FDE31D), [G:9C6D1224](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-9C6D1224-25F6-416E-A843-EAA1176C244A)) (inference) A headless accoreconsole run cannot do them.

### Project Standards commands ([G:A5915307](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A5915307-EF29-4865-8CA6-7197BDF44429))
Prompts are not documented unless shown.
- [AUTO] AECPROJECTSTANDARDS: opens the Configure AEC Project Standards dialog (blocks a script).
- [AUTO] AECSYNCHRONIZEPROJECTDRAWING: syncs the current drawing with the standards.
- [AUTO] AECSYNCHRONIZEPROJECT: syncs every drawing of the current project.
  - Both run with no user interaction ONLY when the project's sync option is Automatic ([G:A5915307](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A5915307-EF29-4865-8CA6-7197BDF44429), [G:E48B97D2](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-E48B97D2-B94F-4CC1-BE4C-5F8990F2961E)).
- [AUTO] AECAUDITPROJECTDRAWING / AECAUDITPROJECT: audit the current drawing / project. Report only; nothing changes ([G:5A4A4196](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5A4A4196-A57C-4F01-9D9E-27543A1D6367)).
- [AUTO] AECSHOWOBJECTDISPLAYOVERRIDES (scripting table, [G:A5915307](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A5915307-EF29-4865-8CA6-7197BDF44429)) and AECSHOWDISPLAYOVERRIDES (task page, [G:026853F9](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-026853F9-436C-44F9-852E-AB2E01CF4AD3)): the 2027 help uses both names for "find object-level display overrides". Prompt: `O` (byObject) highlights them, `S` (byStyle) lists them in the command window, `B` (Both). Probe which name runs before scripting.
- [AUTO] AECVERSIONMODIFIEDOBJECTS: versions all modified styles and display settings. Standards drawings only.
- [AUTO] AECPROJECTSTANDARDSSETUPREPORT: tracking report of the standards setup.
- [AUTO] AECUPDATESTANDARDS: pushes the current drawing's styles and display settings into the standards.
- [AUTO] AECPURGEVERSION: deletes version history AND current version info. Standards drawings only ([G:0D3D6090](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-0D3D6090-E838-4AC2-B8C1-8C52F9480115)).
- [AUTO] AECCLEARVERSIONHISTORY: deletes all versions except the current one. Standards drawings only ([G:49D4B0F0](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-49D4B0F0-8326-42EF-9957-5C14E97AB9B9)).
- [AUTO] AECSYNCHRONIZEWSTANDARDS: syncs the standards drawings with each other (spelled this way in the 2027 table).
- [AUTO] AECUPDATEPROJECTCADSTANDARDS: updates the project CHX batch-checker file and each drawing's DWS associations.
- [AUTO] XLOADCTL must be 2 (the default) for project standards ([G:B9479240](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-B9479240-6946-4C2A-8E0F-A162E91FE084)).

## 10.2 Hard rules that prevent wasted runs
1. Never move, copy, rename or delete project DWG, XML or APJ files in File Explorer. Use Project Browser / Project Navigator. Explorer changes give inconsistent project data. Navigator edits (rename, delete, property change) cannot be undone with UNDO. ([G:5F593182](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5F593182-A1B1-4913-8FE3-2F39B38FD76E), [G:BDA8F9DF](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-BDA8F9DF-B9C2-4014-B783-E12C9CAC90CD), [G:37FD55CE](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-37FD55CE-D564-4E7F-8879-60D007FD6327), [G:5DF55C84](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5DF55C84-541F-4A6E-8703-69DC13C646FD), [G:B039680B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-B039680B-4883-4291-A988-2223440DE4E1))
2. In a project, reference project drawings into each other only through Project Navigator. Xrefs made in the Xref Manager or on the command line do not use project data (a construct's level elevation as its Z insertion) and the host XML lacks the load info, so they can later show "Not Found". ([G:FAFDA97C](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-FAFDA97C-9718-47A6-87C9-6487CDBAAEA4), [KB:000288882](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Xref-in-View-drawing-not-found-in-AutoCAD-Architecture-or-AutoCAD-MEP.html)) (inference) A scripted -XREF / XATTACH on a project drawing bypasses Drawing Management.
3. Never delete the XML files beside project drawings unless you mean to strip the project context. ([G:44EEF898](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-44EEF898-9DB9-4F12-943C-D6A9F96BC41B), [G:FAFDA97C](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-FAFDA97C-9718-47A6-87C9-6487CDBAAEA4), [G:1EB35CD7](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-1EB35CD7-2076-4798-ABA8-91CF0E65743D))
4. Setting a project current migrates it to the current release format. Repath, Move, Rename or a standards sync re-saves drawings in the current DWG format; older releases cannot open them. ([G:5F593182](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5F593182-A1B1-4913-8FE3-2F39B38FD76E), [G:7D18FB7F](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-7D18FB7F-0BB0-41C5-8919-0E02364C3837), [G:4B0FD48F](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-4B0FD48F-44DF-4FC2-B4F1-535104B1A357), [G:37FD55CE](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-37FD55CE-D564-4E7F-8879-60D007FD6327))
5. One project current per session. Opening a DWG that belongs to another project does not switch projects. ([G:F0F79C8F](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-F0F79C8F-4D04-48A8-B955-552F23994B47), [G:48A25C81](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-48A25C81-BC11-4664-94A7-E251EE568F5F), [KB:000601604](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Opening-a-file-from-a-different-project-does-not-automatically-open-the-project-in-Project-Navigator-in-AutoCAD-Architecture-or-AutoCAD-MEP.html))
6. Close a construct, element or view drawing before deleting it. Deleting a category deletes the drawings in it. ([G:F7C72F69](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-F7C72F69-D259-425B-858E-5AAF2988F64F), [G:911EC78B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-911EC78B-6E9F-4918-B118-AE4564150389), [G:BA360E42](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-BA360E42-4B6F-4CC8-9541-E1C63D76F5F6), [G:151FC8A0](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-151FC8A0-1124-4061-9BC1-3E9E7E083B6B))
7. Do not keep projects in OneDrive, Dropbox, Google Drive, Box, A360 or SharePoint sync folders. Use a local or LAN folder. Autodesk Docs / Forma Data Management hosting is the supported cloud route. ## 10.3 Sending drawings to people without MEP

### Pick the route by what the recipient has
- Recipient has the MEP or ACA toolset, same or newer release: send the DWG as is; use eTransmit to include xrefs and fonts ([G:D8318B84](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-D8318B84-885F-4EF3-B8E2-22C162CA17D0)). Template-project "Consultant Backgrounds" views are saved with the Screened display configuration and can go to toolset users as is ([G:C7351090](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-C7351090-9244-4572-A0FA-6FEB024F9039)).
- Recipient has an older release and needs to SEE the objects: set PROXYGRAPHICS = 1 before down-saving. Objects display as drawn but are not editable; without it they show as boxes ([KB:000266207](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/AutoCAD-Architecture-MEP-AEC-Objects-not-showing-in-previous-versions-of-AutoCAD.html)). Plain AutoCAD users can also install an MEP object enabler ([G:844D9600](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-844D9600-5957-4495-836D-FE708C33CE46)).
- Recipient needs editable plain geometry (plain AutoCAD, other CAD, Revit, Navisworks workarounds): EXPORTTOAUTOCAD on the drawing (below). Not reversible: the original keeps the intelligence, the copy does not ([KB:000630080](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/MEP-objects-in-DWGs-from-AutoCAD-MEP-are-displayed-as-a-box-in-non-AutoCAD-applications.html)).
- Plain-AutoCAD consultant, template-project route: set the display configuration to Plan Only, then SAVEAS a non-ACA version ([G:C7351090](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-C7351090-9244-4572-A0FA-6FEB024F9039)).
- Other CAD shows MEP objects as a bounding box because it reads only standard objects: EXPORTTOAUTOCAD on a copy, or send IFC ([KB:000630080](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/MEP-objects-in-DWGs-from-AutoCAD-MEP-are-displayed-as-a-box-in-non-AutoCAD-applications.html), [KB:000644341](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Is-it-possible-to-import-or-export-drawing-from-AutoCAD-Architecture-or-MEP-to-other-CAD-programs.html)).
- Last resort: EXPLODE a COPY twice. First explode turns a part/fitting into an anonymous block and sets Z to 0; second gives lines, arcs, splines. Connectivity is lost for good. Meant for users with no MEP, no object enabler, or an AutoCAD version the Export to AutoCAD commands do not support. ([G:844D9600](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-844D9600-5957-4495-836D-FE708C33CE46))
- Before sending: BLDSYSPURGE (unused MEP objects), Style Manager purge of unused system definitions, then AutoCAD PURGE ([G:1BC89887](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-1BC89887-2FB9-4C17-A575-0A6BF8104FDF), [G:88979D90](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-88979D90-A9C8-4869-B690-A18541DE0FC2), [G:2514F0D1](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-2514F0D1-3117-4D15-95D9-6DC78949354E)).

### EXPORTTOAUTOCAD
- What it does: a NEW drawing with all MEP objects exploded into basic AutoCAD objects. The new drawing is created but NOT opened. The original is unchanged. ([G:BFE06821](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-BFE06821-2369-4398-B271-FAAEE75300BD), [G:86C80CA1](https://help.autodesk.com/view/ACD/2027/ENU/?guid=GUID-86C80CA1-F237-4AE6-8A43-2E9CA06A03A8))
- Conversion follows the selected view: 3D view objects become AutoCAD solids; plan view objects become linework. Xref geometry becomes linework inside a block reference (explode it to free the linework). Layers, colors and linetypes are kept. ([G:BFE06821](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-BFE06821-2369-4398-B271-FAAEE75300BD))
- [GUI] Application menu > Export > AutoCAD > pick the format (the MEP page still shows "AutoCAD 2000") > "Export drawing name" dialog > Save. ([G:BFE06821](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-BFE06821-2369-4398-B271-FAAEE75300BD))
- [AUTO] Command-line prompts (Core [G:86C80CA1](https://help.autodesk.com/view/ACD/2027/ENU/?guid=GUID-86C80CA1-F237-4AE6-8A43-2E9CA06A03A8), ACA [G:A174C49B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A174C49B-2FB3-47F4-9ECA-35C700650263)). The main prompt is "Enter for Filename" with these options:
  - Format: enter `F`. The ACA page lists AutoCAD 2013, 2010, 2007, 2004, 2000, R14.
  - Bind: Yes = bind all xrefs, xref-dependent named objects merged into the new drawing. No = keep xrefs as links.
  - Bind Type (when Bind = Yes): Bind = keep xref-dependent names; Insert = merge names without the original file name.
  - Maintain: Yes = explode block instances inside AEC objects into basic objects (they revert to their own properties); No = leave those blocks unexploded.
  - Prefix / Suffix: added to the current file name. Use Prefix to avoid overwriting the source name.
  - `?`: lists the current settings.
  - Core page note: options can differ by toolset. Keyword letters other than `F` are not given. (inference) Run `?` once in a live session before scripting the answers.
- KB route for an older version: -EXPORTTOAUTOCAD > Format option > pick version. A new drawing with prefix ACAD lands in the same folder as the original. ([KB:000251620](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Error-This-drawing-contains-custom-objects-when-saving-in-AutoCAD.html))
- GOTCHA 3D fittings: if the active display set shows fittings with the 2 Line representation, an export from a 3D view turns those fittings into linework instead of solids. Before exporting, switch to a display configuration (or edit the current display set in Display Manager) so fittings use the Model representation. ([KB:000479482](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Exporting-to-AutoCAD-from-AutoCAD-MEP-will-create-fittings-not-as-3D-solids.html))
- GOTCHA colors: exported objects get their layer color as a hard object color. [AUTO] Run SETBYLAYER on everything in the exported DWG to put them back to ByLayer, or restore a saved layer state. ([KB:000602805](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/EXPORTTOAUTOCAD-from-AutoCAD-MEP-or-Architecture-sets-ACE-and-MEP-colors-to-be-byobject-instead-of-bylayer.html))
- Also the fix for: blocks with AEC data that vanish when copied between drawings ([KB:000480475](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Blocks-copied-between-two-drawings-disappear-in-AutoCAD.html)); a DWG that hangs on xref attach and cannot be repaired ([KB:000371687](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Application-hang-when-attaching-an-xref-into-s-specific-drawing-file-in-AutoCAD.html)); ArcView/ArcGIS custom-object problems ([KB:000251620](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Error-This-drawing-contains-custom-objects-when-saving-in-AutoCAD.html)).

## 10.6 Xrefs in MEP drawings
Standalone (non-project) use. Inside a Drawing Management project use Project Navigator instead (10.2 rule 2).
- [GUI] Insert tab > Reference panel > Attach > Select Reference File > "Attach External Reference" dialog > Reference Type = Attachment or Overlay > insertion point, scale, rotation, or Specify On-screen > OK. ([G:CD9F2073](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-CD9F2073-511E-404E-99BE-F2D7FE33BE29)) The MEP pages name no command-line form. (inference) Core AutoCAD XATTACH / -XREF is the script route; see the core AutoCAD section for its prompts.
- Attach vs Overlay, conflicting help text:
  - [G:CD9F2073](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-CD9F2073-511E-404E-99BE-F2D7FE33BE29) says Attachment "Saves a copy of the xref drawing in your drawing" and Overlay "Creates a link to the xref drawing in your drawing."
  - [G:45203A5A](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-45203A5A-EB2C-40CF-A685-65B8CAC73F07), [G:06447446](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-06447446-A13B-45A9-9508-79CF9C1ACFB5), [G:F0C07E18](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-F0C07E18-A30F-4BEE-8D3E-EE7AEF3A6864) and [KB:000455093](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Reference-not-displayed-in-a-Sheet-drawing-in-AutoCAD-Architecture-MEP.html) describe both as links that differ by NESTING: an overlaid xref is not shown when its host is itself attached or overlaid into another drawing; an attached xref is carried along.

## 10.7 Drawing Management: model, files, palette

### The model
- Project = building model (constructs + elements) plus reports (views + sheets). References chain: elements > constructs > views > sheets. Sources can sit in many folders or on a network, and several people can work at once. ([G:D6713577](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-D6713577-2537-49B1-BCAD-47C9779A48CA), [G:E4420B66](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E4420B66-22D0-482A-9BA2-CA982B7278F6))
- MEP use: model the systems in 3D in constructs; a view references the model at one scale (e.g. an HVAC section, a lighting plan); views go on sheets for plotting or transmittal. Edit only the model; views and sheets follow. ([G:7B2F5167](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-7B2F5167-E1B6-4D37-947C-56BE78A90E73))
- Project Browser creates and picks projects and holds high-level data (number, name, contacts, locations of drawing templates, tool palettes, the project Content Browser library). Project Navigator holds levels, divisions, project drawings and sheets. ([G:E4420B66](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E4420B66-22D0-482A-9BA2-CA982B7278F6))
- Construct: one unique part of the building (core, apartment, whole floor) on one level and one division; a spanning construct (curtain wall, elevator shaft) is on several. Holds drawn objects, element xrefs, or both. ([G:D6713577](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-D6713577-2537-49B1-BCAD-47C9779A48CA), [G:24051115](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-24051115-1562-42B1-B617-B2A54F61061F))
- Element: a reusable building block DWG (desk/chair set, typical bathroom, repeated layout) referenced into constructs, other elements or sheets. It shows in views only through a construct. ([G:D4AA4FD5](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-D4AA4FD5-B5A3-462F-BC1F-945C602E9FAE), [G:3B256F58](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-3B256F58-1515-45EB-B3C2-5032D82D0E5A), [G:A855D7FD](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A855D7FD-F6F1-4139-94DF-42A300D190AB))
- View drawing: references the constructs for a chosen part of the building; three types, each with its own template: General, Detail, Section/Elevation. Annotation (tags, dimensions, schedules) belongs in views by recommendation ([G:D6713577](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-D6713577-2537-49B1-BCAD-47C9779A48CA), [G:8B5A731E](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-8B5A731E-3CDE-4258-9644-14081DE74A77)).
- Model space view: a named, bounded area of a view drawing with its own scale and layer settings ([G:7215BEF5](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-7215BEF5-02F2-449E-8780-6730BFF88B47), [G:8B5A731E](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-8B5A731E-3CDE-4258-9644-14081DE74A77)).
- Sheet: a paper space layout registered as a sheet. Sheet view: the paper space viewport made by dropping a view or model space view on a sheet. Sheet drawing: a DWG holding one or more sheets. Sheet set: the one ordered collection of all project sheets, built for Publish. ([G:D6713577](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-D6713577-2537-49B1-BCAD-47C9779A48CA), [G:56FFCC9B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-56FFCC9B-7946-46CC-9086-2C9D26830C3D))
- Interference detection works in the current drawing, in xrefs, or between them; results are mass elements that can be tagged and scheduled ([G:05FBC0C8](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-05FBC0C8-0C33-4A67-90C6-46EDECB5E329)).

([G:D504FE6A](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-D504FE6A-0FD9-4244-A18B-ED14AF8ECA5D), [G:3962F6CE](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-3962F6CE-6F61-4EE5-9C6B-1C96EC940C90))

## 10.9 Levels, divisions, constructs, elements
All [GUI] in Project Navigator unless marked. Renaming or recategorizing any project file raises the "Project Navigator - Repath Project" dialog (see 10.11).

### Levels
- A new project has one level (ground floor, elevation 0) and one division. Changing the first level's elevation sets the default for new levels. ([G:67BE542D](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-67BE542D-88D2-47B4-9C1E-3DF3A5D6BDF6), [G:D6713577](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-D6713577-2537-49B1-BCAD-47C9779A48CA))
- Create: Project tab > button under Levels > Levels dialog. "Auto-Adjust Elevation" on = each new level starts on top of the one below. Add above: the add-level button or right-click > Add Level Above. Add below: right-click > Add Level Below (negative elevation below ground with Auto-Adjust). Inserting between levels re-adjusts the ones above or below. ([G:6FE230C6](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-6FE230C6-13E9-47AD-9A92-A6419E2B0A5A))
- Fields: Name (unique; it is the key used to assign constructs), Floor elevation, Floor-to-floor height, ID (usable in schedule tables), Description. OK, then Yes in the next dialog to push the change through the project. ([G:6FE230C6](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-6FE230C6-13E9-47AD-9A92-A6419E2B0A5A), [G:15EA7465](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-15EA7465-4C4C-4535-BAB7-F28D86B15E9D))
- Edit with Auto-Adjust ON: changing one level's elevation or height shifts the others (first floor 3 m to 4 m moves level 2 from 3 m to 4 m). Clear Auto-Adjust first to stop that; without it fix the other levels by hand to avoid gaps or overlaps. Check that construct contents still fit the level height. ([G:15EA7465](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-15EA7465-4C4C-4535-BAB7-F28D86B15E9D), [G:82E18221](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-82E18221-1315-4866-8777-F671AEA2BB38))
- Rename a level: assigned constructs follow. Change a level ID: schedule text changes. ([G:82E18221](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-82E18221-1315-4866-8777-F671AEA2BB38))
- Copy a level with its constructs: Levels dialog > right-click level > Copy Level and Contents > right-click another level > Paste Level Above / Paste Level Below > rename, ID, description > OK > Yes. Copies appear on the Constructs tab with " (2)" appended; rename them; click refresh. ([G:24B79001](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-24B79001-1D04-4C3C-91F2-9670D429808A))
- Delete: Levels dialog > right-click > Delete Level > OK > Yes. Its constructs are NOT deleted; they become orphaned (delete or reassign them). Views keep working until updated, then show the level missing. ([G:189AAD36](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-189AAD36-E0B7-411A-A527-26A356D92E87), [G:82E18221](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-82E18221-1315-4866-8777-F671AEA2BB38))
- Level elevation display precision comes from the construct template (or the common model/view template) UNITS precision, not from a level setting. Edit that DWT's UNITS and restart if overwritten. ([KB:000545537](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Changing-elevation-precision-of-Levels-in-AutoCAD-Architecture-or-MEP.html))

### Divisions
- A division splits the building horizontally (a wing). Most projects use one. ([G:C8CA8C32](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-C8CA8C32-6EB9-4620-ACBF-7C9B597122C7))
- Create: Project tab > button under Divisions > right-click > Add Division (or the add button). Name is unique (the assignment key); ID feeds schedules; Description; listed in creation order. ([G:87D0DFC6](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-87D0DFC6-A8DF-4CA0-BF6C-2B3D959F5B2F), [G:5AA13300](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5AA13300-0FEB-42DF-B5AD-F767D8C8D3E2))
- Rename: constructs follow. Change ID: schedule text changes. Delete (right-click > Delete Division > OK > Yes): constructs are orphaned, not deleted; views need a new selection. ([G:5A5ED984](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5A5ED984-E64D-4B36-9914-EB971C13B97C), [G:A037FAA8](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A037FAA8-E96B-4AE1-9688-A17C68A624C6))
- Divisions can hold alternates; include the right division when generating a view ([G:C7A22B59](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-C7A22B59-819A-4CAF-A45C-2DF0F5504353)). Walls clean up across divisions if baselines are at the same elevation ([G:8D9CAF02](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-8D9CAF02-CAAC-4373-9A3C-A6B8F302DC8B)).

Level or division change = reload xrefs in views or regenerate views (AECREGENERATEPROJECTVIEWS). ([G:9D4C52D1](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-9D4C52D1-7FD8-42D6-AF57-48990323BB3A), [G:2ECDB228](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-2ECDB228-6251-4029-A4EE-9EAE95F57FAB), [G:EB629654](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-EB629654-BB95-46EE-B488-4EC420C25793), [G:CE5A2127](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-CE5A2127-98A7-4DF0-B83D-986436618C65))

Do not attach property sets to an overlaid construct from the host; attach them inside it. ([G:36583E8A](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-36583E8A-04A1-4186-AD3E-E36938146EB7))

## 10.13 Project Standards
Pages are ACA 2027; MEP shares the feature ([G:E02A5760](https://help.autodesk.com/view/BLDSYS/2027/ENU/?guid=GUID-E02A5760-1412-44EE-BADB-1B1154AE1F5F)). They never name pipe or duct styles. (inference) MEP system definitions and styles live in Style Manager, so they should behave like any other style; probe before relying on it.

### What it is
- OFF by default. Keeps standard styles, display settings and AutoCAD standards in step across every drawing of a project ([G:5336E004](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-5336E004-73C3-4295-A010-D5CDFAEB2B87), [G:7C233A4F](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-7C233A4F-630C-49A7-8176-E8EE3E55E3F8)).
- AEC standards = everything in Style Manager and Display Manager: object styles, property set definitions, property data formats, schedule table styles, classification definitions, display theme styles, layer key styles, mask block definitions, material definitions, multi-view block definitions, profile definitions, display properties, display sets, display configurations ([G:825A14B9](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-825A14B9-07B5-4AB2-8CCD-C6C54F2AAAB0), [G:732BFBCB](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-732BFBCB-4DDE-49EC-88A0-8CB8C8E6EC6C)).
- Prerequisites: drawings must be in a project; at least one standards drawing; only ONE drawing may hold the standard display settings; standards files are DWG, DWT or DWS; AutoCAD standards (layers, text styles, linetypes, dimension styles) MUST be DWS; [AUTO] XLOADCTL = 2. ([G:B9479240](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-B9479240-6946-4C2A-8E0F-A162E91FE084), [G:A2E72C15](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A2E72C15-460A-4EBD-A464-01A325021A76))
- Keep materials and classifications in the same standards drawing as the styles that use them; keep dependent styles (doors and windows inside assemblies) together ([G:825A14B9](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-825A14B9-07B5-4AB2-8CCD-C6C54F2AAAB0), [G:9AFF00CC](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-9AFF00CC-D934-4F3D-B1DA-7595EA3FFB24)).
- A standards drawing is an ordinary file that becomes one when added to the configuration. It is NOT a project drawing and is not listed in Project Navigator; open it with Open > Drawing. ([G:B346330D](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-B346330D-CB71-4416-A673-27473E324BB6), [G:49D4B0F0](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-49D4B0F0-8326-42EF-9957-5C14E97AB9B9))
  - INSIDE the project folder = project-specific: copied and repathed with a template project, copied with standards copies, included in standards-with-each-other sync and in eTransmit/archive.
  - OUTSIDE = department/company: referenced, not copied; skipped by each-other sync and by eTransmit/archive; one change reaches every project that syncs. ([G:B346330D](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-B346330D-CB71-4416-A673-27473E324BB6), [G:732BFBCB](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-732BFBCB-4DDE-49EC-88A0-8CB8C8E6EC6C))

### Workflow ([G:134D16D7](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-134D16D7-7213-4EB6-A6B7-B70B79D332FD))
1. Build standard styles, display settings and AutoCAD components in one or more DWG/DWT/DWS files.
2. Optional: a tool catalog from them; optional: a project Content Browser library.
3. Associate the standards drawings with the project; with several, say which style types each controls.
4. Pick the sync mode.
5. Copy standards into project drawings (palette tools, library tools, or Style Manager/Display Manager).
6. Synchronize; fix what is out of step.

([G:E48B97D2](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-E48B97D2-B94F-4CC1-BE4C-5F8990F2961E), [G:604E324D](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-604E324D-2081-4C74-9A54-3AF4295CAD62))

### Sync modes (one setting for ALL users of the project) ([G:651E734B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-651E734B-06CD-4188-95E9-F66F461BE5A0))

### Versions and identity
- Every style and display setting carries a version: GUID, date and time, Windows login of the last editor, optional comment. "Identical" = same object type + same name + same GUID. No property-by-property comparison is made. ([G:22719521](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-22719521-E959-4DDC-8DEF-19175A2E5D17), [G:9AFF00CC](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-9AFF00CC-D934-4F3D-B1DA-7595EA3FFB24))
- Project drawings: a new version is made automatically each time the item is changed in Style Manager or Display Manager (Apply or OK) and saved. Standards drawings: you MUST version by hand; saved but unversioned edits are not pushed. ([G:22719521](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-22719521-E959-4DDC-8DEF-19175A2E5D17), [G:9EBFB2E7](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-9EBFB2E7-19AC-446F-93DE-4CFD4AD41B6C), [G:C13693FD](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-C13693FD-4D28-4929-88E7-C5CB59176411))
- Status ([G:9D9685AF](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-9D9685AF-B152-4E04-9E02-6498B9C3BE09), [G:732BFBCB](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-732BFBCB-4DDE-49EC-88A0-8CB8C8E6EC6C)):
  - Current version: no action.
  - Older version (GUID found in the standards history): Update from Standards / Do not Update (asks again next time) / Ignore.
  - Nonstandard (newer) version (GUID not in the history): overwrite from standards, or update the standards from the drawing.
  - Not standardized (no match, or its style type is not tied to that standards drawing): Skip / Ignore.
- Icons in Style Manager/Display Manager: blue = standard and in sync; outdated; nonstandard (newer); excluded from sync; no version information; changed but not versioned (standards drawings only); gray = not standardized. ([G:C13693FD](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-C13693FD-4D28-4929-88E7-C5CB59176411), [G:BD29B0D6](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-BD29B0D6-59B4-4ECC-AB5D-115D455656FB), [G:18B1A5E4](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-18B1A5E4-986A-4170-AB46-552EA7F8607B))
- Never versioned and never overwritten by sync: display configuration cut plane; display set Live Section on/off; display set surface hatch on/off; wall graph toggle ([G:22719521](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-22719521-E959-4DDC-8DEF-19175A2E5D17), [G:C13693FD](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-C13693FD-4D28-4929-88E7-C5CB59176411)).
- Version history only tells the current state; it cannot roll back ([G:22719521](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-22719521-E959-4DDC-8DEF-19175A2E5D17)).
- Version tools: Manage tab > Project Standards panel > Apply Versioning To Current Drawing (select items, one comment) ([G:28737BD2](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-28737BD2-291A-40A8-A7B3-1D0FE33BAF04)); per item: Version History tab > Version ([G:9EBFB2E7](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-9EBFB2E7-19AC-446F-93DE-4CFD4AD41B6C)); [AUTO] AECVERSIONMODIFIEDOBJECTS ([G:A5915307](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A5915307-EF29-4865-8CA6-7197BDF44429)). ### Changing the standards
- Change types ([G:F06E006B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-F06E006B-B29E-4478-BF3C-114E70D30023)):
  - Modify: version it, save the standards drawing, sync the project (and the other standards drawings).
  - Rename: acts as a NEW style and cannot be synced. Copy the renamed item into project drawings, reassign it, remove the old name.
  - Add: create, save, copy into project drawings; later syncs include it.
  - Delete: only in the standards drawing; leftover instances show as not standardized. Sync never deletes anything.
- Edit directly: open the standards drawing > Style Manager or Display Manager (standards drawings sit under the project node) > edit > Version History tab > Version > comment > OK > save > sync. Needs write access; a Lock icon means read-only (you can edit but not save). ([G:9EBFB2E7](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-9EBFB2E7-19AC-446F-93DE-4CFD4AD41B6C))
- Promote a not-standardized item from a project drawing: open the project drawing from Project Navigator > Style Manager or Display Manager > select item(s), a type, a category or the whole drawing > right-click > Update Standards from Drawing ([AUTO] AECUPDATESTANDARDS) > LOWER panel Action: "Add to Project Standards", "Skip" or "Ignore" > OK > OK/Apply > Yes to save the standards drawing > sync. A style goes to the FIRST standards drawing tied to its type; the type must be ticked for that drawing or it stays not standardized. ([G:420AC75B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-420AC75B-CA93-4FA8-9AE7-733B0BC29959), [G:FE9DDF08](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-FE9DDF08-B0D4-46D5-BEC5-5BE32307BF99))

## 10.14 Project tool palettes and tool content root path

### The project tool palette group
- Each project has ONE tool palette group (ATC), tied to it automatically. It shows in the tool palettes set when the project is set current, but ONLY if it holds at least one palette. A new project's group is empty unless its settings point at an existing group. ([G:1F10C63A](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-1F10C63A-B835-4C1E-9774-D20F90C8BEB9), [G:E0A83914](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-E0A83914-1496-46B2-85CD-11C9B98CAF46), [G:6F020F7E](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-6F020F7E-AC40-4E7B-A039-E25A45FD0714))
- Making a project current appends one path (the project tool palette file location) to the current profile; closing the project or setting another current removes it ([G:52143A0C](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-52143A0C-941E-49C6-981D-9C2E5B4229A8)).
- Settings: Project Properties > Tool Palettes ([G:BF337D6F](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-BF337D6F-3B87-48E4-A202-B9DAF8D25CCC), [G:A7EBE259](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A7EBE259-5C27-4627-BA2F-D5A41F1F626E)):
  - Tool Palette File Location: local or network folder.
  - Project Tool Palette Group (storage type): Shared Workspace Catalog = path added to the project profile (AWS) and the catalog is read from that location; Per User Workspace Catalog = palettes copied to a per-user folder ([G:BF337D6F](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-BF337D6F-3B87-48E4-A202-B9DAF8D25CCC) gives `C:\My Documents\Autodesk\My Projects\<project name>`, [G:A7EBE259](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A7EBE259-5C27-4627-BA2F-D5A41F1F626E) gives `\Documents and Settings\<User Name>\`); None = disabled and the other Tool Palettes fields hide.
  - Tool Content Root Path and Content Browser Library (below).
- Default location when none is set ([G:BF337D6F](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-BF337D6F-3B87-48E4-A202-B9DAF8D25CCC), [G:A7EBE259](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-A7EBE259-5C27-4627-BA2F-D5A41F1F626E)):

  - From the default ACA template project: same path, one empty palette, displayed.
  - From your own template project: the group is copied with its palettes if it sat inside the template project folder; otherwise the new project shares the same group.
- Not auto-displayed: new no-template project not pointed at a group; legacy project not redirected; template project with storage type None or with no palettes ([G:E0A83914](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-E0A83914-1496-46B2-85CD-11C9B98CAF46)).
- Show or fill an empty group [GUI]: Home tab > Build panel > Tools drop-down > Design Tools > tool palettes title-bar button > Customize Palettes > right-click the palettes list > New Palette > name > drag it onto the project group > Close ([G:E0A83914](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-E0A83914-1496-46B2-85CD-11C9B98CAF46), [G:6F020F7E](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-6F020F7E-AC40-4E7B-A039-E25A45FD0714)).

New palettes show next time the project opens. Use Shared storage so everyone gets the changes. ([G:C9358288](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-C9358288-85BD-437B-8CF2-7807F5A22E37))

### Shared vs per user ([G:52143A0C](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-52143A0C-941E-49C6-981D-9C2E5B4229A8))

([G:8A7387AB](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-8A7387AB-ED22-43D3-920A-04DE7638C5BA), [G:79B744CA](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-79B744CA-40B2-447F-B026-CB5C6BECBF42))

## 10.16 Batch resave of old projects (promote.bat) ([G:46DF786B](https://help.autodesk.com/view/ARCHDESK/2027/ENU/?guid=GUID-46DF786B-412F-4925-81F4-462E088DFE58))
All [AUTO]: a batch file writes a .scr; the script opens, saves and closes every drawing.
- Back up first. If the project was copied to a new place, repath it with the ORIGINAL older release before promoting.
- Make it: paste the batch text from the help page into Notepad, save as `promote.bat`, run it from a Command Prompt (administrator recommended).
- Syntax: `promote.bat [projectName] [projectLocation] [scriptName] [promotionTarget]`. Example: `promote.bat MyProject R:\Projects\Old\ promote.scr R:\Projects\New`. Quote arguments with spaces. Exactly 4 arguments, else it prints usage and prompts ("What is the name of the project?", "Where can it be found?", script name, target directory).
- Behavior: starts with PAUSE (needs a key press); re-prompts if `<location>\<name>` is missing, if the script name already exists, or if `<target>\<name>` already exists; copies with `xcopy <src> <dest> /E /I /Q /H`, then `attrib -A -R <dest> /D /S`; writes `_open "<file>"`, `_qsave`, `_close` for every DWG, then every DWT; lists DWS files but does NOT script them (open and save each DWS by hand, same names); deletes the copy if nothing was found. The script lands in the folder where promote.bat runs.
- Run order it prints: start the program with NO project active; turn off the old-version dialog with [AUTO] AecFileOpenMessage = No; check the copy has the same file count; run the script; resave the DWS files; then set AecFileOpenMessage back to Yes.
- Any dialog during an open stops the script. Edit the .scr to delete everything up to the last drawing saved, remove the cause, rerun the trimmed script.

## 10.17 Troubleshooting from support articles

### Projects that will not open or list
- Fatal unhandled exception (e06d7363) when opening Project Navigator or Project Browser: the project path changed. Double-click the APJ and accept the repath, or reset settings to defaults. ([KB:000607815](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Opening-the-Project-Navigator-or-Project-Browser-lead-AutoCAD-Architecture-or-MEP-products-to-crash-with-a-Fatal-Error.html))

[AUTO, file ops] Swap in the backup `<projectname>.DS$` as the DST; if that fails, delete both and open the APJ so a new sheet set is built. On a network drive, make sure the folder allows content indexing. If the project folder itself shows as a plain folder, IT can clear its file attributes with ATTRIB. ([KB:000279746](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/Project-does-not-display-in-Project-Browser-in-AutoCAD-Architecture-or-AutoCAD-MEP.html))
